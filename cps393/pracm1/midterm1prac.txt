########## Q0) 

Start by creating three directories, q1, q2, and q3 in the 
home directory on your test computer. Do this by opening a

In these directories, you will create the programs for the 
three questions described below.

Feel free to create as many additional files as you want to

########## Q1: 3 marks)

Write a Bash program in folder q1/ called "q1_max_line" 
that takes a file name as a command-line argument and prints 
the line in the file containing the largest number of words.
Additionally, print the number of words on that line.

Print the result to stdout as follows (inlcude quotes around
line contents):

"<line>" has <xx> words

Your program may assume the file exists and is readable. You
should create your own file to test your program.

########## Q2: 3 marks)

Write a Bash program in folder q2/ called "q2_char_compressor" 
that accepts a file name as input. 

You should test that the file exists, and that it is readable.
If the file does not exist, or is not readable, you should 
exit with a code of 1. No need to print an error message.

From here, the program will print the contents of the file to
stdout, with all sequences of repeating characters replaced by 
a single instance of that character. For example, if the file 
contains the following line:

Hello howwwww arrrrre yooouuu??

Your program should print the following to stdout:

Helo how are you?

You should create your own file to test your program.

########## Q3: 4 marks)

Write a Bash program in folder q3/ called "q3_file_indexer" 
that accepts two arguments:

$1 - One of C, W, or L. The argument corresponds to 
     characters, words, or lines.
$2 - A file name. You may assume the file exists, and is
     readable.

Your program should create a copy of the file. The name
of the file should be appended to include the count
specified by the first argument. The file extension, if
it exists, should be unmodified.	

For example, if your script is run as follows:

./q3_file_indexer W file1.txt

...and file1.txt contains 42 words, then the copy 
should be created as:

file1_42W.txt
