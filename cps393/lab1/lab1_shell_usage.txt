PART 0) Using the scp command

scp, or "secure copy", can be used to copy files from a remote
location to your local machine. Its usage is as follows:

scp <source file> <destination file>

The difference between this command and cp, is that the source
or destination can be a remote path. In the example below, I'm
copying the lab0 file (lab0_getting_started_ssh.txt) to my local 
working directory:

scp aufkes@moon.cs.torontomu.ca:/usr/courses/cps393/aufkes/labs/lab0/lab0_getting_started_ssh.txt .

This command can be used on your own local machines to copy
files from moon, or to moon. This command is presented for your
information only. There is nothing to submit for this question.

PART II) Editing text files

From your home directory, using a text editor of your choice, 
create a file called name.txt that contains the following 
information, in the following format:

You may use any text editor you wish, as long as it's being done 
from the shell. Nano and pico are more modern (and easier to use),

nano is recommended.

Whatever you pick, make sure you get comfortable with it. 
These are the editors you'll have access to on the tests.

PART III) Changing file permissions using CHMOD

Give TWO chmod commands that accomplish each of the following. One chmod 
command can use symbolic notation, the other should use octal notation.

 a) You have a file named script.sh with current permissions -rw-r--r--. 
    How would you grant execute permission to the owner and group while 
    keeping read-only access for others? 
 b) A directory "project/" has permissions drwxr-xr-x. Give the group to 
    permission to create and delete files in this directory but prevent 
    others from accessing it. Leave the owner perms as-is.
 c) A file data.txt needs permissions where the owner can read, write, and 
    execute, the group can read and write, and others can only read.
